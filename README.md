# Richman Portfolio Risk Manager

개인 포트폴리오용 리스크 관리 웹앱입니다.

## 가격 업데이트 방식
실시간 시세 대신 **매 거래일 오후 8시(KST) 최종 확정 가격**을 사용합니다.
`data/closing_prices.json`이 오후 8시에 자동 갱신되고, 웹앱은 이 파일을 읽어 계좌를 재계산합니다.

## 주요 기능
- SK하이닉스 / 삼성전자 / SK스퀘어 / 삼성전기 최종가격 반영
- 평가금액, 손익, 순자산, 신용융자, 담보비율 추정
- 하이닉스 기준 담보비율 170/160/150/140% 임계가격 역산
- 매수 / 매도 / 입금 / 출금 / 신용상환
- 계좌 스냅샷과 로컬 히스토리
- 투자일기 자동 생성
- AI 리스크 코치용 요약
- JSON 백업

## 리스크 기준
- 최대 누적 손실: 100,000,000원
- 월간 손실 한도: 20,000,000원
