# Richman Portfolio Risk Manager

개인 포트폴리오용 리스크 관리 웹앱입니다.

## 가격 업데이트 방식
한국 거래시간에는 **약 5분 간격의 장중 현재가**를 사용하고 화면은 1분마다 새 파일을 확인합니다.
`data/market_prices.json`에는 시가와 현재가가 함께 저장되며, 현재가는 평가금액·손익·순자산·담보비율 계산에 반영됩니다.
장 마감 후에는 마지막 가격을 종가로 유지하고, 장중 시세 연결 실패 시 `data/closing_prices.json`의 마지막 확정 종가를 사용합니다.

## 주요 기능
- SK하이닉스 / 삼성전자 / SK스퀘어 / 삼성전기 장중 현재가와 시가 반영
- 평가금액, 손익, 순자산, 신용융자, 담보비율 추정
- 하이닉스 기준 담보비율 170/160/150/140% 임계가격 역산
- 매수 / 매도 / 입금 / 출금 / 신용상환
- 계좌 스냅샷과 로컬 히스토리
- 투자일기 자동 생성
- AI 리스크 코치용 요약
- JSON 백업

- 월간 손실 한도: 20,000,000원
